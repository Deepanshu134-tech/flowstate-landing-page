FlowState — Premium Home Page
Hey there 👋

This is FlowState — a premium landing page I built for a project management tool designed specifically for freelance developers. The idea came from a simple observation: most project management tools feel like they're built for big companies with dedicated project managers. Freelancers just want something that stays out of the way so they can actually code.

This page is my attempt at making that feel real.

What's Inside
Hero section — Tries to explain what the product does in the first few seconds. Simple headline, clear CTA, no fluff.

Animated stats — The numbers count up when you scroll to them. I added a little pulse effect at the end just to make it feel more polished.

Interactive dashboard — This is the part I'm happiest with. The tasks are clickable — you can mark them complete and the remaining count updates automatically. It's a small thing, but it makes the page feel alive instead of just being a static screenshot.

Dark mode — Works everywhere. I used CSS custom properties so everything toggles together — no half-dark elements.

Responsive — I tested it at 390px (small mobile) and 1440px (large desktop). No horizontal scroll, no broken layouts.

Easter egg — Konami code (↑ ↑ ↓ ↓ ← → ← → B A) triggers confetti. It's just for fun.

What I Used
Nothing fancy here. Just:

HTML5

CSS3 (with custom properties for theming)

Vanilla JavaScript (no frameworks)

Inter font from Google Fonts

I kept it simple because I wanted the page to load fast and be easy to maintain. No build step, no dependencies, no headache.

Why I Built This
This was part of an assessment where I had to choose between building a scraper or a landing page. I went with the landing page because I wanted to show that I can think about the user experience — not just write code that works.

The brief was to make something that makes you go "wow, I want an account" in the first 3 seconds. I'm not sure if I fully nailed that, but I tried to focus on what actually matters: clear messaging, good spacing, restraint with animations, and making sure every part of the page serves a purpose.

What I'd Do Differently
If I had more time, I'd:

Connect the dashboard to a real backend with actual data

Add authentication so users could see their own projects

Make the tasks draggable and editable

Test across more browsers and screen sizes

But for now, I'm happy with how it turned out.

A Quick Note About Honesty
One thing the assessment emphasized was no fake testimonials or made-up numbers. So the stats you see (12,000 tasks, 3,400 freelancers, etc.) are labeled as "internal beta data." No fake logos, no fabricated quotes. Just a clean page with real effort behind it.
